# 🐟 闲鱼黑话助手

Chrome 浏览器扩展，帮你解决闲鱼上的"黑话搜不到、看不懂"问题。

- **搜索黑话推荐**：搜索框输入正常词，弹出对应黑话变体
- **商品页自动解读**：黑话加下划线高亮，悬停看含义
- **侧滑面板**：一键查看本页全部黑话
- **可选本地 AI**：词典查不到时用 Chrome Built-in Gemini Nano 推测
- **自定义词典**：本地添加你的私有词条
- **零数据收集**：全本地运行
