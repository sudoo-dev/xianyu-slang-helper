# 🐟 闲鱼词典

Chrome 浏览器扩展，帮你解决闲鱼上的"暗语搜不到、看不懂"问题。

- **搜索暗语推荐**：搜索框输入正常词，弹出对应暗语变体
- **商品页自动解读**：暗语加下划线高亮，悬停看含义
- **侧滑面板**：一键查看本页全部暗语
- **可选本地 AI**：词典查不到时用 Chrome Built-in Gemini Nano 推测
- **自定义词典**：本地添加你的私有词条
- **零数据收集**：全本地运行
