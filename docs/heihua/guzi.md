# 「谷子」是什么意思？谷圈黑话入门

> **一句话答案：谷子 = 二次元周边商品**（英语 **goods** 的音译，和小米/粮食没有任何关系）。买周边叫「**吃谷**」，这个圈子叫「**谷圈**」。

## 谷圈核心黑话

| 黑话 | 词源 | 含义 |
|---|---|---|
| **谷子** | goods 音译 | 二次元周边统称 |
| **吃谷** | — | 购买谷子 |
| **吧唧** | 日语バッジ (badge) | 圆形徽章，最大品类 |
| **痛包** | 日语 痛バッグ | 透明展示层的包，用来插吧唧 |
| **海景房** | 比喻 | 痛包/卡册里最显眼的 C 位 |
| **柄图** | 日语 柄 | 谷子上的图案 |
| **色纸** | 日语 色紙 | 签绘板/方形卡纸周边 |
| **立牌** | — | 亚克力立像 |
| **谷美** | — | 谷子摆拍装饰美化 |

## 交易黑话（闲鱼高频）

| 黑话 | 含义 |
|---|---|
| **排烧** | 排队求购（烧 = 热望）|
| **捆卡 / 捆售** | 必须打包一起买 |
| **切售** | 从套装里拆出来单卖 |
| **蹲** | 蹲守求购，「蹲一个 XX 吧唧」|
| **同担拒否** | 拒绝和喜欢同一角色的人交易 |
| **爆炒** | 稀有谷子被炒高价 |
| **天价谷** | 被炒到离谱价格的谷子 |

## 实战例句

- 「出 XX **吧唧**，**海景房**保护，**捆卡**出不拆」
- 「**蹲**一套 XX **色纸**，**排烧**可等」
- 「**同担拒否**，介意勿拍」
