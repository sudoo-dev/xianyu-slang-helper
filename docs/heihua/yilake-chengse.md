# 「伊拉克成色」是什么意思？

> **一句话答案：伊拉克成色 = 外观惨烈但（通常）功能正常**。词源是"像从伊拉克战场淘回来的"的梗——机身磕碰划痕拉满，能用，便宜。这是闲鱼上少见的**自嘲式诚实**成色描述。

## 闲鱼成色黑话从新到旧排序

| 黑话 | 实际含义 | 水分提示 |
|---|---|---|
| **全新未拆 / 原封** | 未开封 | 注意「后封」造假 |
| **充新** | 「充过几次电、几乎全新」 | ⚠️ 翻新机高频话术，见[防坑专题](../nvdaxuesheng/) |
| **99 新** | 几乎无痕迹 | 数字全靠自觉 |
| **98 新** | 仅激活/极轻微痕迹 | 同上 |
| **95 新** | 轻度使用、细看有划痕 | 相对诚实的常用档 |
| **9 成新** | 明显使用痕迹 | — |
| **战损** | 有硬伤（磕角/裂纹）| 通常伴随实拍 |
| **伊拉克成色** | 外观惨烈、功能尚可 | 反而多为真实描述 |
| **女生自用** | 暗示轻度爱惜使用 | ⚠️ 经典话术，未必可信 |

## 为什么「伊拉克成色」反而值得看？

敢这么写的卖家通常是**真便宜、真如实**——描述越惨、心理落差越小。对比之下，「充新」「女生自用」这类**往好里说**的话术才需要提高警惕。
