# 「女大学生自用」是什么套路？防坑黑话识别指南

> **一句话答案：这是一个「人设话术」**——用"女生、自用、爱惜"的形象暗示东西成色好、来源干净。**它出现的频率远高于女大学生卖闲置的真实比例**，是翻新贩子最爱的开场白之一。看到它 ≠ 有问题，但应该**更仔细**验货，而不是放松警惕。

## 高频防坑黑话拆解

| 话术 | 表面意思 | 风险点 |
|---|---|---|
| **女大学生自用 / 女生自用** | 爱惜使用 | 贩子人设话术高发 |
| **充新** | 充过几次电 | 翻新机重灾区（另见[成色专题](../yilake-chengse/)）|
| **只面交** | 当面交易 | 结合超低价 = 钓鱼引流常用 |
| **不放心看我评价** | 有好评 | 评价可刷，主动强调反而可疑 |
| **加绿泡泡聊** | 加微信谈 | **脱离平台 = 失去保护**，最危险信号 |
| **国行在保** | 保修期内 | 需验序列号，口说无凭 |
| **急出 / 秒发** | 急用钱便宜卖 | 制造紧迫感，配合低价钓鱼 |

## 一分钟防坑流程

1. **凡引导站外交易（微信/QQ）→ 直接 pass**。这是所有骗局的共同第一步。
2. 低于行情价 15% 以上 → 要求视频验货 + **走闲鱼**（平台内交易）。
3. 数码产品让卖家拍**当场序列号/设置页**，翻新机话术（充新/女生自用）经不起这一步。
4. 「只面交」+「急出」+ 低价三连 → 大概率钓鱼。

## 实战例句（学会一眼扫雷）

- 「iPhone 13 **女大学生自用**，**充新**，**急出**」→ 三个风险词叠满，谨慎。
- 「**不放心看我评价**，都是真实买家」→ 主动递证据，反而要多验一步。
