# 闲鱼「小刀」是什么意思？

> **一句话答案：「小刀」= 小幅度砍价**（一般 9 折以内）。「刀」在闲鱼语境里就是砍价，刀的大小 = 砍价的狠度。

## 「刀」系黑话对照表

| 黑话 | 含义 | 例 |
|---|---|---|
| **小刀** | 小幅砍价，9 折以内 | 500 → 460 |
| **小刀价** | 已经是接近底价，只留一点点还价空间 | 「标价即小刀价」|
| **大刀** | 对半砍级别（4-6 折） | 500 → 250 |
| **屠龙刀 / 膝盖斩 / 血刀** | 砍到离谱（1-3 折），多为调侃 | 500 → 100 |
| **接受刀** | 可以还价 | — |
| **不接受任何刀 / 刀客勿扰 / 免刀** | 一口价，别还价 | — |
| **可小刀，大刀勿扰** | 小砍可以，狠砍拉黑 | — |

## 实战例句（真实闲鱼话术风格）

- 「95 新自用 iPad，**可小刀**，大刀直接举报」
- 「标价即**小刀价**，屠龙刀的兄弟建议看看别家」
- 「诚心要的来，**免刀**，包邮」

## 砍价潜规则

1. **先问在不在、东西还在不在**，直接甩低价容易被拉黑。
2. 「小刀」的安全试探是 **9 折**；对方写了「接受小刀」再往下探。
3. 卖家回「**已经很低了**」≈ 还有 5% 空间；回「**成本价了**」≈ 基本到底。
4. 看到「**可刀**」但标价异常低 → 结合[防坑黑话](../nvdaxuesheng/)判断是不是钓鱼。
