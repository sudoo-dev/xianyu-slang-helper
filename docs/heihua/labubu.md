# 拉布布黑话：隐藏款 / 端盒 / 川沙妲己 都是什么？

> **一句话答案：** 「**隐藏款**」= 盲盒里的超低概率稀有款（溢价核心）；「**端盒**」= 整箱买断；「**川沙妲己**」= 网友给拉布布（Labubu）的梗称（诞生于上海川沙的泡泡玛特工厂梗）。

## 潮玩盲盒黑话表

| 黑话 | 含义 |
|---|---|
| **拉布布** | Labubu，泡泡玛特当家 IP |
| **川沙妲己** | 拉布布梗称 |
| **隐藏款 / 隐藏** | 超低概率稀有款，二手溢价数倍 |
| **端盒** | 整箱买断（必集齐普款）|
| **拆盒 / 拆售** | 端盒后拆开单卖 |
| **摇盒** | 靠摇晃听声判断盒内款式 |
| **确认款** | 已拆盒确认款式再卖（无赌运成分）|
| **雷款** | 系列里最不受欢迎的款 |
| **蒂木 / 天木** | Dimoo（另一热门 IP）|
| **茉莉** | Molly |

## 闲鱼买拉布布防坑三件事

1. **「确认款」优先**：避免「代抽」「盲拆」话术里的调包风险。
2. **隐藏款价格对市**：低于市场价太多的「隐藏款」大概率是假货（俗称「假布布」）——先查当日行情再拍。
3. **看清「端盒」是原封还是拼盒**：拼盒 = 卖家自己凑的一箱，可能已被摇盒筛过。
