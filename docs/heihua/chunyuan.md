# 「纯原」是什么意思？球鞋等级黑话全解

> **一句话答案：「纯原」= 仿鞋（假鞋）里的最高等级话术，不是正品。** 看到「纯原 / 公司级 / 通货 / 真标」任何一个词，都等于卖家在明示：这是仿品。（繁体圈写作「純原」，含义相同。）

## 仿鞋等级黑话（卖家话术体系）

| 黑话 | 卖家宣称 | 实际 |
|---|---|---|
| **纯原** | 原厂数据、原厂材料、顶级做工 | 仿品最高档话术 |
| **公司级** | 细节接近专柜 | 高仿 |
| **真标** | 鞋标可过验 | 仿品 |
| **通货** | — | 批量流水仿品 |
| **裁片级** | 用裁片数据复刻 | 仿品营销词 |
| **莆田** | 产地代称 | 仿鞋代名词 |

## 相关正品圈黑话（别搞混）

## 闲鱼买鞋防坑三条

1. **词典排雷**：出现上表任何等级词 = 仿品，不存在「纯原正品」。
2. 明显低于行情的「正品」+ 拒绝平台鉴定 = 走开。
3. 要求**走闲鱼、支持验货宝/得物鉴定**，拒绝的一律 pass（更多见[防坑专题](../nvdaxuesheng/)）。
